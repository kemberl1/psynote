# Справочник маркеров названий медицинских и иных учреждений (уровень 3 docs/04).
# Каждая строка — маркер. Если маркер встречается КАК ОТДЕЛЬНОЕ СЛОВО (с учётом
# границ слова, Cyrillic-aware), вокруг него разворачивается полное название
# (кавычки, "им. ...", номер). Пополняется без перекомпиляции логики.
#
# РЕГИСТР (БАГ №1, precision):
#   - Маркеры-АББРЕВИАТУРЫ, записанные ЗАГЛАВНЫМИ (ГБУЗ, ЦВЛ, ПНД, НИИ, ДГБ …),
#     сопоставляются РЕГИСТРОЗАВИСИМО. Это не даёт окончанию «-нии» в обычных
#     словах («улучшении», «отделении», «линии») совпасть с «НИИ» в нижнем
#     регистре. В реальных данных эти сокращения всегда заглавными.
#   - Полные слова-маркеры (больница, диспансер, поликлиника …) — регистро-
#     НЕзависимы, но ТОЖЕ обязаны стоять как отдельное слово (границы слова).
#
# ВАЖНО: общеупотребительное слово «отделение/отделении» НЕ является названием
# учреждения и СОЗНАТЕЛЬНО НЕ внесено в словарь — его вырезать не нужно.
# Вырезаем конкретные идентифицирующие названия (ГБУЗ «…», больница им. …,
# НИИ … №N), а не общую лексику.
#
